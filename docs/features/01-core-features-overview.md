# 🌟 Core Features Overview

> **Last Updated**: 2026-03-15 | **Version**: 1.5.0

## 🎯 What is ProgressTracker?

ProgressTracker is a **developer progress tracking platform** that helps programmers:
- Monitor activity across 50+ coding platforms
- Set and track learning goals
- Build and maintain coding streaks
- Earn achievements for milestones
- Share progress with the community

---

## 📊 Features at a Glance

### 🔄 Platform Sync
Automatically sync data from connected platforms every 6 hours, or manually trigger a sync anytime.

**Supported platforms**: LeetCode, GitHub, HackerRank, Codeforces, CodeChef, AtCoder, and 45+ more.

→ [Sync Architecture](../sync/01-sync-architecture.md)

---

### 📝 Manual Tracking
Log any activity manually — study sessions, project work, certifications, job applications.

**Categories**: DSA, Git, Learning, Hackathon, Open Source, Company, Design, Data Science, Other

---

### 🎯 Goals System
Set measurable goals with deadlines and get reminders.

**Goal types**: Daily, Weekly, Monthly, Quarterly, Yearly, Streak, Milestone

**Metrics tracked**: Problems solved, commits, time spent, streak days, etc.

→ [Goals System](02-goals-system.md)

---

### 🔥 Streak Tracking
Maintain daily coding streaks with a GitHub-like activity heatmap.

**Features**:
- Visual 365-day heatmap
- Streak milestones (7, 30, 100, 365 days)
- Streak freeze (Pro: 1/month, freeze to protect streak)
- Email alerts when streak is at risk

→ [Streak System](03-streak-system.md)

---

### 🏆 Achievements & Gamification
50+ badges to earn across categories.

**Categories**: Streak badges, Problem-solving badges, Platform badges, Consistency badges

→ [Achievements](04-achievements-gamification.md)

---

### 🔔 Notification System
Multi-channel notifications to keep users engaged.

**Channels**: In-app, Email, Web Push

**Types**: Streak alerts, goal reminders, achievement unlocks, weekly reports

→ [Notifications](05-notifications.md)

---

### 📤 Data Export
Download your data in multiple formats.

**Formats**: CSV, JSON, PDF report, Excel

→ [Export System](06-export-system.md)

---

### 🔗 Profile Sharing
Create a public profile link to share progress with others.

→ [Share & Embed](07-share-embed.md)

---

### 🏅 Leaderboard
Global rankings by points, streaks, or platform-specific stats.

→ [Leaderboard](08-leaderboard.md)
