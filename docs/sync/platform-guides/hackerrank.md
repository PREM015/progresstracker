# 🌐 HackerRank Sync Guide

> **Last Updated**: 2026-03-15 | **Version**: 1.5.0

## ⚡ Quick Setup

1. Go to **Settings → Connected Platforms**
2. Click **Connect HackerRank**
3. Enter your **HackerRank username**
4. Optionally add your **API Key** for more detailed stats
5. Click **Test & Connect**

---

## 📊 What Gets Synced

| Data | Notes |
|------|-------|
| Problems solved | Total by domain |
| Badges earned | Gold, Silver, Bronze |
| Certifications | Passed skill assessments |
| Contest scores | If participated |

---

## 🔑 Getting Your API Key

1. Log in to HackerRank
2. Go to profile → Settings → API Keys
3. Generate a new key
4. Copy and paste into ProgressTracker

---

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| No data showing | Ensure username is correct; profile must be public |
| Badges not appearing | HackerRank may take 24h to update badge counts |
