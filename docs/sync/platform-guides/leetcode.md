# 💻 LeetCode Sync Guide

> **Last Updated**: 2026-03-15 | **Version**: 1.5.0

## ⚡ Quick Setup

1. Go to **Settings → Connected Platforms**
2. Click **Connect LeetCode**
3. Enter your **LeetCode username**
4. Click **Test Connection**
5. If successful, click **Save & Sync**

> **Note**: LeetCode doesn't require OAuth — only your public username is needed.

---

## 📊 What Gets Synced

| Data | Notes |
|------|-------|
| Problems solved (total) | All difficulties |
| Easy / Medium / Hard counts | Breakdown |
| Contest rating | If you participate in contests |
| Acceptance rate | Overall |

---

## ⚙️ Requirements

- Your LeetCode profile must be **public**
- Settings: `Allow other users to view my profile` must be checked

---

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| "Profile not found" | Double-check your username spelling |
| Data not updating | LeetCode may cache profiles; wait 1 hour |
| Shows 0 problems | Ensure profile is public |
