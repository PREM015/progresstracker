# ⚡ Codeforces Sync Guide

> **Last Updated**: 2026-03-15 | **Version**: 1.5.0

## ⚡ Quick Setup

1. Go to **Settings → Connected Platforms**
2. Click **Connect Codeforces**
3. Enter your **Codeforces handle** (username)
4. Click **Test & Connect**

---

## 📊 What Gets Synced

| Data | Notes |
|------|-------|
| Contest rating | Current rating |
| Problems solved | AC submissions |
| Contests participated | Total count |
| Max rating | Historical peak |

---

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| "Handle not found" | Check handle on codeforces.com |
| Rating showing old value | Codeforces API rate limits; retry later |
